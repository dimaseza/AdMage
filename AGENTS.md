# 🧠 Agent Memory & Rules

## 1. Core Rules
- **No Tailwind CSS:** Use Vanilla CSS for maximum flexibility and control unless explicitly requested by the user.
- **Prioritize Aesthetics:** Ensure a premium, modern, and dynamic design (vibrant colors, dark modes, glassmorphism, dynamic animations).
- **No Placeholders:** Use the `generate_image` tool to create working demonstrations instead of using empty placeholders.
- **Consistent Design:** Always adhere to `DESIGN.md` for UI components, colors, and typography.
- **Follow Installed Skills:** Actively utilize guidelines from `frontend-design`, `ui-ux-pro-max`, `web-design-guidelines`, and `codebase-architecture` skills.

## 2. Project Context
- **Product:** AI-powered content creation platform (Refine Image, Text-to-Image, Campaign Image, Video Ads).
- **Tech Stack:** Next.js (Frontend), Next.js API / Express (Backend), PostgreSQL, Cloudflare R2, BullMQ.
